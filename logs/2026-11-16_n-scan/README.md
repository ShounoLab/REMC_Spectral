# データ点数 n を変えたときの F(4) − F(3)（2026-11-16）

**目的**: 「K = 3 と 4 の差が小さいのは，余分なピークのペナルティが特異モデルとして (λ の差) × log n でゆっくり増えるため」
という仮説（[notes](../../notes/2026-11-15_model-selection.md)）を確かめる．
正則モデルならピーク 1 本（パラメータ 3 個）あたり Δλ = 3/2 で，F(4) − F(3) は傾き 1.5 で log n に比例して増えるはず．

**コード**: コミット 68931a5（023efbf に，デモの第 5 引数 n（データ点数．観測範囲 [0, 3] を等間隔）と
第 6 引数 n_replica（レプリカ数）を足した版）．サンプラーと推定器は 921a4bf から変更なし（逆温度列の適応あり，β̂ は補間）．
n = 301 の出力は [ladder-adapt](../2026-11-15_ladder-adapt/README.md) と（実行時間を除き）一致した．

**実行**: `remc-spectral 5 20000 42 <data_seed> <n> 40`，n = 101, 301, 1001, 3001, 10001，data_seed = 1〜8．
10 スレッド．生出力は `n<n>_ds<data_seed>.txt`（40 本）．真のピークと σ = 0.1 は n によらず同じ．

## 所見

- F(4) − F(3) の平均は n とともに増え，n = 101 の −0.11 から n = 10001 の 0.94 になった．
  K̂ = 3 の割合も 3/8 → 8/8 に上がった．n = 301 で決着しなかったのは，平均差 0.12 が組ごとの揺らぎ（標準偏差 約 0.3）に埋もれていたため．
- 傾きは 0.22 ± 0.03 で，正則モデルの 1.5 よりはるかに小さい．余分なピークのペナルティが小さいという仮説の方向とは合う．
  ただし素朴な見積もり（a 方向だけが効くとして 1/2）よりもさらに小さい．
- F(5) − F(3) の傾き（0.43）は F(4) − F(3) の約 2 倍．余分なピーク 1 本ごとにほぼ同じ量が足されている．
- 隣接する n の間の平均の傾きは 0.21, 0.27, 0.11, 0.32（F(4) − F(3)）で，ばらつきが大きく曲がり方は読み取れない．
- **サンプリングの不具合**: n = 101, data_seed = 1 で K = 4 の最小交換率が 0.14，K = 5 が 0.01 だった．この組の F(4)，F(5) は信頼できない．
  ほかの 39 組の最小交換率は 0.31 以上．この組を除いても n = 101 の平均はほとんど変わらない．
  n ≥ 301 だけの回帰も傾きは同じ．
- 交換率は n = 10001 でも 0.46 以上で，L = 40 で足りた．高い β 側のエネルギーの揺らぎはパラメータの次元で決まり，n に依存しないためと考えられる．
- MCMC の seed を変えた再現性は，この実験の n では確かめていない（n = 301 では揺らぎ約 0.05 nat：[mc-seed-scan](../2026-11-14_mc-seed-scan/README.md)）．
