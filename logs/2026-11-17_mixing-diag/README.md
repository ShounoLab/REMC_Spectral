# 各スロットのエネルギー列の自己相関時間（2026-11-17）

**目的**: 各 K の交換モンテカルロが十分に混ざっているか（遷移を稼げているか）を確かめる．
[n-scan](../2026-11-16_n-scan/README.md) の追加確認で，K = 4, 5 の λ̂ が高い β で d/2 を超えたため，非平衡を疑った．

**コード**: コミット 68931a5（サンプラーは 921a4bf から変更なし）．
診断用の小さなプログラム `mixdiag/`（このクレートを path 依存で使う）で `remc::run` を呼び，
各スロットのエネルギー列 nE（本サンプリング 20000 スイープ）の積分自己相関時間 τ_int を Sokal の窓（c = 6）で求めた．
データ・事前分布・Config はデモと同じ（L = 40，burn-in 10000，逆温度列の適応あり，seed = 42）．

**実行**: `mixdiag <n> <data_seed> <K>`．(n, data_seed) = (301, 8), (3001, 1), (10001, 8)，K = 3, 4, 5．
生出力は `n<n>_ds<data_seed>_K<K>.txt`（列: l, β, τ_int, ESS = 20000/τ_int, 次のスロットとの交換率）．

## 結果

τ_int の単位はスイープ．β_0 = 0 のスロットは除く．

|---|---|---|---|
| 301, 8 | 3 | 6.4（3104） | 6.4（β = 4.2） |
| 301, 8 | 4 | — | 23.0（β = 458, ESS 871） |
| 301, 8 | 5 | 3.6（5567） | 556（β = 749, ESS 36） |
| 3001, 1 | 3 | 6.6（3038） | 6.6（β = 0.46） |
| 3001, 1 | 4 | — | 16.6（β = 606, ESS 1202） |
| 3001, 1 | 5 | 3.9（5108） | 1410（β = 807, ESS 14） |

## 所見

- β ≤ 約 400 では，どの K でも τ_int は 3〜9 スイープで，ESS は 3000 以上．真の β = 100 と β̂ の周辺はよく混ざっている．
- K = 5（と n = 10001 の K = 4 の最上段）では，β ≳ 450 で τ_int が数百〜1400 に跳ね，ESS は 14〜36 しかない．
  交換率はこの区間でも 0.3 以上あるので，交換ではなく各温度での局所的な動きが遅い（余分なピークが雑音に当てはまった配置から抜けにくい）と考えられる（未確認）．
- F(K, β̂) は β̂ ≈ 100 までのスロットの比だけで決まるので，この遅いスロットの影響を受けない．
  MCMC seed 間の揺らぎ 0.05 nat（[mc-seed-scan](../2026-11-14_mc-seed-scan/README.md)）とも矛盾しない．
- 一方，n-scan の追加確認で β = 200〜1000 に当てはめた λ̂（K = 4 で 7.14，K = 5 で 9.16）はこの区間を含むので，信用できない．
  β = 50〜300 の値（K = 4 で 5.42，K = 5 で 5.64）はよく混ざった区間だけから求めたもの．
