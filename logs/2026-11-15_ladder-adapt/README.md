# 逆温度列の適応と β̂ の補間（2026-11-15）

**目的**: data-seed-scan で見つかった 2 つの課題（交換率の低い温度区間，β̂ の格子の粗さ）への対処を確かめる．

**コード**: data-seed-scan の版に次を追加（未コミットの作業ツリー）．
- `Config::ladder_interval = 250`: burn-in の前半（5000 スイープ）で 250 スイープごとに
  `remc::adapt_ladder` で隣接交換率をそろえる（利得 κ = 1）．後半と本サンプリングでは列を固定．
- `remc::minimize_free_energy`: 格子上の最小点の両隣を細かく探索し，格子点の間は
  `remc::log_z_at`（スロット l のサンプルの再重み付け）で補間．

**実行**: `remc-spectral 5 20000 42 <data_seed>`，data_seed = 1〜8, 20120401．生出力は `data_seed*.txt`．

## 所見

- **交換率**: K = 5 の最小交換率は 0.10 → 0.43（data_seed 4），0.12 → 0.33（8）に改善した．
  K = 1〜3 の最小交換率も 0.57〜0.68 → 0.63〜0.79 に上がった．
  ただし data_seed 3, 4, 8 の K = 5 では最大と最小の差がまだ 0.35〜0.5 残る．
  適応を止めた後半にボトルネックが現れているか，前半 20 回の更新では収束しきっていない可能性がある（未確認）．
- **β̂**: 95〜106 の連続値になり，真値 100 の周辺に分布するようになった．
  格子が粗かったぶん，F_min は変更前より最大 1.3 nat 下がった（data_seed 4 の K = 3: −243.44 → −244.73）．
- **モデル選択**: argmin K は 9 組すべてで変更前と同じ（K = 3 が 6 組，K = 4 が 3 組）．
  K = 3 と 4 の差は 0.6 nat 未満のままで，この 2 点の改善は結論を変えなかった．
- 検証: `k1_free_energy_matches_quadrature_with_adapted_ladder` で，適応後の列の格子点と
  格子点の間の両方で数値積分との差が 0.04 nat 以下であることを確認した．
