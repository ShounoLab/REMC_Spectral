# β_0 = 0 のスロットを事前分布からの独立サンプリングにした効果（2026-11-17）

**目的**: Nagata さんの助言（β → 0 の極限は一様乱数で）に従い，β_0 = 0 のスロットを
ランダムウォーク Metropolis から「毎スイープ事前分布から独立に引き直す」方式に変えた
（[notes](../../notes/2026-11-17_sampler.md)）．混ざり方と F への影響を確かめる．

**コード**:
- 変更前: 68931a5．
- 変更後: コミット 2b901ee（68931a5 に `Slot::redraw_from_prior` を加えた版）．
  β = 0 のスロットは K 本のピークを `Prior::sample_peak` で引き直し，残差は差分更新する．他のスロットは変更なし．

**実行**:
1. 自己相関時間: [mixing-diag](../2026-11-17_mixing-diag/README.md) と同じ `mixdiag` を変更後のコードで再実行
   （(n, data_seed) = (301, 8), (3001, 1), (10001, 8)，K = 3, 4, 5）．生出力は `tau/`．変更前の値は mixing-diag の生出力．
2. F の比較: `remc-spectral 5 20000 <seed> <data_seed> <n> 40`，seed = 1〜8，
   (n, data_seed) = (301, 20120401), (3001, 1)，変更前と変更後の両方．生出力は `{before,after}_n<n>_ds<data_seed>_seed<seed>.txt`．

## 所見

- β_0 の τ_int は 6〜11 → 約 1 になった（独立サンプル）．β_1 も 2.7〜3.3 → 2.0〜2.4 に短くなった．
- F_min の平均は変更前後で 0.06 nat 以内で一致し，seed 間のばらつき（差の標準誤差 0.03〜0.05）の範囲内．偏りは入っていない．
- seed 間の標準偏差は，K = 1 で 0.035 → 0.016（n = 301），0.047 → 0.029（n = 3001）とほぼ半分になった．
  K ≥ 3 では増えたものと減ったものがあり，はっきりしない（8 回では標準偏差の推定に 3 割程度の誤差がある）．
  K が大きいと，F の誤差の主な出どころは β_0 ではなく，もっと高い β のスロットにあると考えられる．
- β ≳ 450 で K = 5 の τ_int が数百〜1500 になる問題はそのまま残った（局所的な動きの遅さなので，β_0 の変更では直らない）．
- 計算時間は変わらない．
- K = 1 の数値積分との比較（`k1_free_energy_matches_quadrature` とその適応版）は変更後も通った．
