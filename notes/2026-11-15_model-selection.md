# モデル選択の検討：K = 3 と K = 4 が区別しにくい

## 経緯

1. デフォルト実行で argmin K = 4（真値 3）．ΔF(3) = 0.35 と小差．
2. MCMC の seed を変えても K = 4 が最小のまま → 揺らぎではなく系統的（[logs](../logs/2026-11-14_mc-seed-scan/README.md)）．
3. **[利用者]** seed を変えてもデータは固定だと気づく → data_seed を引数化．
4. データを変えると 9 組中 6 組で K = 3（[logs](../logs/2026-11-15_data-seed-scan/README.md)）．
   最初のデータで K = 4 になったのはそのデータ実現値のせい．

## アイディアと状態

### 交換率の低い温度区間を burn-in 中に検出して調整する — 実装済み（921a4bf）
- **[利用者]** 交換率の低下と β 格子の粗さを，burn-in や実験初期に計測して調整する機構の提案．
- **[Claude]** 交換率は burn-in 前半に隣接交換率をそろえる方向に逆温度列を動かす（`adapt_ladder`）．
  後半は固定して平衡化，本サンプリングでは不変（詳細釣り合いのため）．
  交換率は隣接温度のエネルギー分布の重なりの指標なので，log Z の比推定の精度にも直結する．
- 結果: 最小交換率 0.10 → 0.43 など改善．ただし K = 5 で不均一さが残るデータがある
  （[logs](../logs/2026-11-15_ladder-adapt/README.md)）．

### β̂ の分解能 — 実装済み（921a4bf）
- **[Claude]** これはサンプリングではなく推定の問題なので，burn-in での調整ではなく
  再重み付けで格子点の間の log Z(β) を求める方式にした（`log_z_at`，`minimize_free_energy`）．
  隣接比と同じ推定量なので格子点で一致し，追加の計算はほぼゼロ．
- 結果: β̂ が 95〜106 の連続値に（真値 100）．

### K = 3 と K = 4 の差が小さい理由 — 検討中（n 依存性は確認，傾きの解釈は未解決）
- **[Claude]** a ~ Exp(1) は a ≈ 0 に確率を残すので，余分なピークを足しても自由エネルギーがあまり増えない．
  特異モデルでは余分な成分のペナルティが (λ の差) × log n でゆっくり増える．n = 301 では差が小さいのと矛盾しない．
- 確かめ方の案:
  - n（データ点数）を変えて F(4) − F(3) の平均が log n に比例して増えるか見る．
  - a の事前分布の形（ゼロ近傍の密度）を変えて差がどう変わるか見る．（未着手）
- **結果（2026-11-16）**: n = 101〜10001 で F(4) − F(3) の平均は −0.11 → 0.94 と増え，
  log n への傾きは 0.22 ± 0.03（F(5) − F(3) は 0.43）．正則な 1.5 よりずっと小さく，仮説の方向とは合う．
  n ≥ 1001 ではほぼ K = 3 が選ばれる（[logs](../logs/2026-11-16_n-scan/README.md)）．
- ただし傾き 0.22 は素朴な見積もり（a 方向だけが効くとして 1/2）よりも小さい．
- **[Claude]** ⟨nE⟩_β を 1/β に当てはめると λ を 1 組のデータから読める（⟨nE⟩_β ≈ c + λ/β）．
  n = 10001 の 1 組で K = 1〜3 は d/2 に一致したが，K = 4, 5 は β の範囲で λ̂ が 5.4〜7.1（K = 4）と変わり，
  d/2 = 6 を超える範囲もある．β ≈ 100 付近の実効的な Δλ は約 0.9 で，n スキャンの傾き 0.22 と合わない．
- 傾きが小さい理由の候補（どれも未検証）:
  - **[Claude]** 余分なピークが雑音に当てはまる利得（最小 nE の差）が n とともに増える．
    μ が自由で，b ~ Gamma が細いピークを許すので，n が増えると当てはめられる「位置の数」が増え，
    利得が log n 程度で伸びて λ log n のペナルティを打ち消す（混合モデルの尤度比が有界でない問題に近い）．
    F(4) − F(3) ≈ Δλ log β̂ + β̂ (min nE₄ − min nE₃) + 定数 の第 2 項の n 依存性を見れば切り分けられる．
  - **[Claude]** log log n の項（多重度 m）．n = 101〜10001 では実効的な傾きが λ − (m − 1)/log n ≈ λ − 0.14 (m − 1) になる．
    これだけで 1/2 → 0.22 を説明するには m − 1 ≥ 2 が必要．
  - **[Claude]** 漸近領域に入っていない．真のピーク 2 本（μ = 1.0, 1.4）が重なっていて，余分なピークがその分け方で得をする．
  - λ̂ が d/2 を超えるのは，余分なピークの「a ≈ 0 でさまよう」状態と「雑音に当てはまる」状態の切り替わり
    （比熱のピーク）を見ているか，高い β で平衡化していないか．
  - **（2026-11-17 追記）** 高い β の非平衡でほぼ説明がつく．K = 5 は β ≳ 450 で τ_int が数百〜1400 スイープ（ESS 14〜36）だった
    （[logs](../logs/2026-11-17_mixing-diag/README.md)）．β = 200〜1000 の λ̂ は捨て，β = 50〜300 の値（K = 4 で 5.42）を使う．
    それでも実効的な Δλ ≈ 0.9 と n スキャンの傾き 0.22 の食い違いは残る．
