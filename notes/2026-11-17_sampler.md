# サンプラーの改善

## β_0 = 0 のスロットを事前分布からの独立サンプリングにする — 実装済み（2b901ee）

- **[利用者]** Nagata さんから「β → 0（温度無限大）の極限は一様乱数にしたほうがよい」と助言をもらった．
- **[Claude]** 現状（68931a5）: β_0 = 0 のスロットも他と同じ単一成分のランダムウォーク Metropolis で，
  目標分布は事前分布 φ そのもの．ステップ幅は受理率 0.4 に合わせて適応している．
  - 自己相関時間 τ_int（エネルギー列）は β_0 で 6〜11 スイープ．β_1 の 2〜3 より長く，
    β ≤ 400 の範囲では最も遅い（[logs](../logs/2026-11-17_mixing-diag/README.md)．所見の表では β_0 を除いていた）．
  - log Z の最初の比 log ⟨exp(−β_1 nE)⟩_φ はこのスロットのサンプルだけで決まる．
- **[Claude]** 助言の解釈: β = 0 の目標は φ（Exp × U × Gamma）で，直接サンプルできる（μ は一様乱数）．
  毎スイープ φ から独立に引き直せば，それ自体が目標分布を不変にする正しい遷移核なので詳細釣り合いは保たれる．
  - 期待する効果: (1) β_0 のサンプルが独立になり，最初の比の推定の分散が下がる．
    (2) 毎スイープ新しい配置が β_0 に供給され，交換で上の温度に運ばれる（列全体の大域的な混ざりの源になる）．
  - コストは 1 スイープの約 1/3（K·n の評価 1 回）で，むしろ安い．
  - スロットごとの乱数ストリームを使えば再現性の不変条件は保てる．ただし乱数の消費が変わるので，既存の記録とはビット単位で一致しなくなる．
- 確かめ方の案: 実装前後で β_0 の τ_int（1 になるはず），F(K, β̂) の MCMC seed 間の揺らぎ，K = 1 の数値積分との差を比べる．
- **結果（2026-11-17）**: β_0 の τ_int は 6〜11 → 約 1，β_1 も 3 → 2 程度に．F_min の平均は変わらず（0.06 nat 以内），
  K = 1 の seed 間の揺らぎは約半分になったが，K ≥ 3 でははっきりしない．β ≳ 450 の K = 5 の遅さは残った
  （[logs](../logs/2026-11-17_beta0-prior/README.md)）．
- **[利用者]** 解釈は「事前分布からの直接サンプリング」で合っていると確認．
