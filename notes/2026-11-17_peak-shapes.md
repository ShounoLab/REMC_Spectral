# ピーク形状の拡張（Lorentz，疑似 Voigt，Voigt）

## ガウス以外の基底を入れる — トレイトの導入は実装済み（1c94501），各形は未着手

- **[利用者]** ガウスだけでなく Lorentz，疑似 Voigt，Voigt の基底を入れられるかという質問．
- **[Claude]** 交換モンテカルロと自由エネルギーの推定はピークの形に依存しない
  （エネルギー nE = SSE/2，差分残差更新，交換，log Z はどれも「ピークの和」であることしか使っていない）．
  変更はピーク関数・パラメータの組・事前分布の側に閉じる．
- 現状で形に依存している箇所: `Peak`（a, μ, b 固定），`Param` と `PARAMS`（3 個），`Prior`，
  `Slot` の `step`/`acc`/`tried`（`[_; 3]`），`RemcResult::acceptance`，main.rs の事後平均の表示，テストの真のピーク．
- **[Claude]** 設計案: 形をトレイト（パラメータ数を定数で持つ）にし，`Chain`/`Slot`/`run` をその型でジェネリックにする．
  評価は最内ループにあるので，実行時の分岐（enum）より静的ディスパッチの方がよい．
  ガウスの結果がビット単位で変わらないことを回帰テストにできる．
- 形ごとの論点:
  - Lorentz: a / (1 + b (x − μ)²)．パラメータ 3 個で，K = 1 の数値積分テストがそのまま使える．
    裾が重いので，観測範囲外の μ や幅の広いピークがベースラインのように振る舞いうる．
  - 疑似 Voigt: η L + (1 − η) G．η ∈ [0, 1] が 1 個増える（事前分布は U(0, 1) か Beta）．
    G と L の幅を共通にするか別にするかで次元が変わる．
  - Voigt: G と L の畳み込み．Faddeeva 関数 w(z) が必要で，Rust の標準にはない．
    自前実装（Humlíček や Weideman の近似，精度は既知の値で検証）か依存クレートの追加（要相談）．
    1 点あたりの評価は exp の数倍〜10 倍程度重い見込み（未計測）．
  - 4 パラメータの形では K = 1 の格子積分（4 次元）が重く，検証方法を別に考える必要がある．
  - 幅 → 0 で Voigt → Lorentz，η → 0, 1 の端など，形のパラメータにも特異点が増え，λ が変わる．
- **[Claude]** 応用: F(K, 形) を比べれば，ピーク数と同時にピークの形もモデル選択できる．
- 利用者に決めてもらうこと: 必要な形と優先順位，疑似 Voigt の幅の扱い，
  形を全ピーク共通にするかピークごとに変えるか，Voigt の実装方法（自前か依存クレートか）．

## Shirley バックグラウンドまで見据えた設計 — 検討中

- **[利用者]** 最終的には Shirley 法のバックグラウンドを入れるところまで視野に入れたい．そのためにトレイトを導入する方向．
- **[Claude]** モデルのピークから作る形にする:
  f(x) = Σ_k [ g_k(x) + s S_k(x) ] + (c₀ + c₁ x)，S_k(x) = ∫_x^∞ g_k(x′) dx′（向きは設定）．
  - ピーク k の寄与を g_k + s S_k にまとめれば，ピークの更新は今と同じく O(n) の差分更新．
  - s やベースラインの係数は全体パラメータ．ΣS_k を 1 行として持てば，s の更新も O(n)．
  - 事前分布は s ≥ 0（Exp か Gamma），ベースライン係数は範囲を決めた一様分布か正規分布にして，正規化された分布であることを保つ．
  - 交換，log Z，β_0 の引き直し（全体成分も事前分布から引き直す）は変わらない．
- **[Claude]** トレイトは 2 つに分ける案:
  1. ピークの形（`eval` と，Shirley 用の累積積分 `cumulative`）．`cumulative` の既定はデータ格子上の累積台形和で，
     閉じた形があるもの（ガウス: erf，Lorentz: arctan，疑似 Voigt: その混合）だけ上書きする．Voigt は既定のまま．
     格子が粗いときの誤差は要検証．
  2. 全体成分（バックグラウンド）: K に依存しないパラメータ（s，c₀，c₁）．「なし」「定数」「Shirley＋直線」などを切り替える．
- erf は Rust の標準にない．自前で実装するか `libm` などのクレートを足すか（依存の追加は要相談）．
- 利用者に決めてもらうこと: s を全ピーク共通にするかピークごとにするか（ピークごとだと a_k → 0 で s_k が決まらず特異性が増える），
  段差の向き（結合エネルギーか運動エネルギーか），ベースラインの次数，erf の実装方法．
